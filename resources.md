# Resources

A small, curated link collection of useful tools, libraries, and inspiration for
design and development. For agent skills, see [external skills](external-skills.md)
and [the skill collection](.skills/).

## Design

- [fontzz](https://fontzz.vercel.app/) — Original type families with weights from
  100 to 900, available under the SIL Open Font License.
- [ASCII Magic](https://www.ascii-magic.com/) — Browser-based tool for turning
  images and videos into ASCII art and applying effects such as dithering,
  halftones, and pixel art.
- [Paper Shaders](https://shaders.paper.design/) — A collection of customizable
  shader effects, image filters, and logo animations for web designs, with a React
  package for integration.
